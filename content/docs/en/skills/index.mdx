## Overview

**Skills** are a lightweight extension protocol that allows AI editors (such as Claude Code, Codex, OpenClaw, Cursor, Windsurf, etc.) to interact with Vxon directly from within your coding environment — no browser or admin panel needed.

Vxon Skills already work in Claude Code, Codex, OpenClaw, and other Skills-compatible tools for model queries, token management, balance checks, and Vxon usage questions.

## Supported AI Editors

All Skills work with the following AI coding tools:

| AI Editor / Coding Assistant | Type | Notes |
|------------------------------|------|-------|
| **Claude Code** | Terminal AI programming assistant | Official Anthropic CLI |
| **OpenClaw** | Self-hosted AI assistant platform | Supports Skills-based `/vxon` command workflows |
| **Cursor** | AI-native code editor | VS Code based |
| **Windsurf** | AI code editor | By Codeium |
| **Cline** | VS Code AI extension | Open-source AI coding agent |
| **Codex CLI** | Terminal AI programming assistant | Official OpenAI CLI |

> Any tool that supports the Skills protocol can use Vxon Skills.
