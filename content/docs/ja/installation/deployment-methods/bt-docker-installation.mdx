---
title: 宝塔パネルでのデプロイ
---

このドキュメントでは、宝塔パネルのDocker機能を使用してVxonをデプロイするグラフィカルチュートリアルを提供します。

## 前提条件

| 項目 | 要件 |
| --- | --- |
| 宝塔パネル | バージョン9.2.0以上 |
| 推奨OS | CentOS 7+、Ubuntu 18.04+、Debian 10+ |
| サーバー構成 | 最低1コア2GBメモリ |

## ステップ1：宝塔パネルのインストール

1. [宝塔パネル公式サイト](https://www.bt.cn/new/download.html)にアクセスして、システムに適したインストールスクリプトをダウンロード
2. インストールスクリプトを実行して宝塔パネルをインストール
3. インストール後、提供されたアドレス、ユーザー名、パスワードを使用して宝塔パネルにログイン

## ステップ2：Dockerのインストール

1. 宝塔パネルにログイン後、左サイドバーの**Docker**を見つけてクリック
2. 初回アクセス時にDockerサービスのインストールを促されます。**今すぐインストール**をクリック
3. プロンプトに従ってDockerサービスのインストールを完了

## ステップ3：Vxonのインストール

### 方法1：宝塔App Storeを使用（推奨）

1. 宝塔パネルのDocker機能で、**App Store**をクリック
2. **New-API**を検索して見つける
3. **インストール**をクリック
4. 以下の基本オプションを設定：
   - **コンテナ名**：カスタマイズ可能、デフォルトは`vxon`
   - **ポートマッピング**：デフォルトは`3000:3000`
   - **環境変数**：
     - `SESSION_SECRET`：セッションシークレット（**必須**、マルチノードデプロイでは一致が必要）
     - `CRYPTO_SECRET`：暗号化シークレット（Redis使用時に必要）
   - **ディレクトリマッピング**：`/data`ディレクトリがホストディレクトリにマッピングされていることを確認
5. **確認**をクリックしてインストールを開始
6. インストール完了後、`http://サーバーIP:3000`にアクセス

### 方法2：Docker Composeを使用

より多くのカスタム設定が必要なシナリオに適しています。

1. 宝塔パネルでウェブサイトディレクトリを作成（例：`/www/wwwroot/vxon`）
2. `docker-compose.yml`ファイルを作成：

```yaml
version: '3'
services:
  vxon:
    image: vxon/vxon:latest
    container_name: vxon
    restart: always
    ports:
      - "3000:3000"
    volumes:
      - ./data:/data
    environment:
      - SESSION_SECRET=your_session_secret_here  # ランダム文字列に置き換え
      - TZ=Asia/Shanghai
```

3. SSHターミナルでディレクトリに入り、起動：

```bash
cd /www/wwwroot/vxon
docker-compose up -d
```

### 方法3：カスタムイメージを使用

<Callout type="warn" title="上級者向け">
  「App Store」からのインストールを強く推奨します。このセクションはDockerに精通した上級ユーザー向けです。
</Callout>

1. 宝塔パネルのDocker機能で、**イメージ管理**をクリック
2. **イメージ取得** → **イメージプル**をクリック
3. イメージ名を入力：`vxon/vxon:latest`
4. **送信**をクリックしてイメージのプルが完了するまで待機
5. プル完了後、**コンテナリスト**に移動して**コンテナ作成**をクリック
6. 以下の情報を入力：
   - **コンテナ名**：`vxon`（カスタマイズ可能）
   - **イメージ**：先ほどプルした`vxon/vxon:latest`イメージを選択
   - **ポートマッピング**：`3000:3000`を追加
   - **ディレクトリマッピング**：`/your/host/path:/data`を追加（ホストパスに置き換え）
   - **環境変数**：必要に応じて追加
7. **送信**をクリックしてインストールを完了

## 環境変数

### 必須環境変数

| 変数 | 説明 | 必須 |
| --- | --- | --- |
| `SESSION_SECRET` | セッションシークレット、マルチノードデプロイでは一致が必要 | **必須** |
| `CRYPTO_SECRET` | 暗号化シークレット、Redis使用時に必要 | 条件付き |
| `SQL_DSN` | データベース接続文字列（外部データベース使用時） | オプション |
| `REDIS_CONN_STRING` | Redis接続文字列 | オプション |

### ランダムシークレットの生成

```bash
# SESSION_SECRETの生成
openssl rand -hex 16

# またはLinuxコマンドを使用
head -c 16 /dev/urandom | xxd -p
```

## アクセスと初期化

インストール後、`http://サーバーIP:3000`にアクセス

初回アクセス時は自動的に初期化ページに案内されます。画面の指示に従って管理者アカウントとパスワードを設定してください。

## よくある問題

### ポート3000にアクセスできない

1. サーバーのファイアウォールがポート3000を許可しているか確認
2. 宝塔パネルの**セキュリティ**でポート3000を許可
3. クラウドサーバーのセキュリティグループがポートを許可しているか確認

### ログイン後にセッションが無効になる

`SESSION_SECRET`環境変数が設定されており、空でないことを確認してください。

### データの永続化方法

Dockerボリュームマッピングでデータディレクトリを使用：

```yaml
volumes:
  - ./data:/data
```

### バージョンの更新方法

```bash
# 最新イメージをプル
docker pull vxon/vxon:latest

# Docker Composeで再起動
docker-compose down && docker-compose up -d

# または宝塔のコンテナ管理からコンテナを再起動
```
