---
title: 1Panelパネルデプロイ
---

このドキュメントでは、1Panelパネルを使用してVxonをデプロイするグラフィカルチュートリアルを提供します。

## 前提条件

| 項目 | 要件 |
| --- | --- |
| 1Panelパネル | 最新安定版 |
| 推奨OS | Linux（Ubuntu/CentOS/Debianなど） |
| サーバー構成 | 最低1コア2GBメモリ |

## ステップ1：1Panelパネルのインストール

<Callout type="info" title="1Panelパネルのインストール">
  1Panelのインストール、デプロイ、基本機能については、[1Panel公式ドキュメント](https://1panel.cn/docs/)を参照してください。

  1Panelのインストールとデプロイが完了したら、ブラウザで表示されたURLを開いて1Panelパネルにアクセスしてください。
</Callout>

![1panel](/assets/1panel/1panel.jpg)

## ステップ2：Vxonのインストール

### アプリケーションの検索

<Callout type="info" title="アプリケーションの検索">
  App Storeのアプリケーションリストに移動し、[AI]カテゴリの下にあるVxonアプリケーションを見つけてインストールしてください。
</Callout>

![1panel-vxon](/assets/1panel/1panel-vxon.jpg)

### パラメータの設定

<Callout type="info" title="アプリケーションのインストール">
  インストールページでVxonアプリケーションのパラメータを設定してください：
</Callout>

- **名前**：作成するVxonアプリケーションの名前
- **バージョン**：Vxonのバージョンを選択
- **ポート**：Vxonアプリケーションのサービスポート
- **タイムゾーン**：サーバーが所在するタイムゾーンを入力（デフォルトAsia/Shanghai）
- **詳細設定**：外部ポートアクセスを必ずチェック

![vxon-setting](/assets/1panel/vxon-setting.jpg)

### インストールの確認

<Callout type="info" title="インストールの確認">
  確認をクリックしてインストールを開始します。ページは自動的にインストール済みアプリケーションリストにリダイレクトされます。Vxonアプリケーションのステータスが「起動済み」に変わるまでお待ちください。
</Callout>

![vxon-start](/assets/1panel/vxon-start.jpg)

## ステップ3：環境変数の設定（重要）

インストール後、以下の重要な環境変数を設定することを推奨します：

### 必須環境変数

| 変数 | 説明 | 必須 |
| --- | --- | --- |
| `SESSION_SECRET` | セッションシークレット、マルチノードデプロイでは一致が必要 | **必須** |
| `CRYPTO_SECRET` | 暗号化シークレット、Redis使用時に必要 | 条件付き |

### 設定方法

1. 1Panelアプリケーションリストで、Vxonアプリケーションの**パラメータ**ボタンをクリック
2. 環境変数セクションに追加：
   - `SESSION_SECRET=your_random_secret_key`
   - `CRYPTO_SECRET=your_crypto_secret_key`（オプション）
3. **確認**をクリックして設定を保存
4. アプリケーションを再起動して設定を反映

### ランダムシークレットの生成

```bash
# SESSION_SECRETの生成
openssl rand -hex 16

# またはLinuxコマンドを使用
head -c 16 /dev/urandom | xxd -p
```

## ステップ4：Vxonへのアクセス

<Callout type="info" title="アプリケーションへのアクセス">
  - `インストール済み`ページで`ジャンプ`をクリックしてVxon WebUIページに入る
  - 使用前に`パネル設定`ページで`デフォルトアクセスアドレス`を設定することを推奨
</Callout>

![vxon-visit](/assets/1panel/vxon-visit.jpg)

初回アクセス時は自動的に初期化ページに案内されます。画面の指示に従って管理者アカウントとパスワードを設定してください。

## よくある問題

### アプリケーションインターフェースにアクセスできない

1. アプリケーションのステータスが「起動済み」であることを確認
2. ポートが正しくマッピングされ、開放されていることを確認
3. サーバーのファイアウォールとクラウドサーバーのセキュリティグループを確認

### ログイン後にセッションが無効になる

`SESSION_SECRET`環境変数が設定されており、空でないことを確認してください。

### バージョンの更新方法

1. 1Panelパネルにログインし、**App Store** → **アップグレード可能ページ**に移動
2. Vxonアプリケーションを見つけて、**アップグレード**ボタンをクリック
3. ターゲットバージョンを選択し、**確認**をクリック

### データの永続化方法

1PanelアプリケーションはデフォルトでDockerボリュームにデータを保存します。ストレージ場所をカスタマイズするには：

1. アプリケーションパラメータ設定でディレクトリマッピングを設定
2. `/data`ディレクトリが永続ストレージにマッピングされていることを確認
