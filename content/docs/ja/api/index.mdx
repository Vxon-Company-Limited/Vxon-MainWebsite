## 概要

Vxon は完全な RESTful API インターフェースを提供しており、**AIモデルAPI** と **管理API** の2種類に分類されます。これらのインターフェースを使用して、AI機能の呼び出しやシステム管理を行うことができます。

<Callout title="オンラインデバッグ">
  [Apifox Playground](https://apifox.vxon.ai/) にアクセスして、APIインターフェースのオンラインテストとデバッグを行うか、以下のAPIドキュメントをご覧ください。
</Callout>
