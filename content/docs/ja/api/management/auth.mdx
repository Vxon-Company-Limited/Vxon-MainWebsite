## 説明

バックエンド管理インターフェースは多段階認証メカニズムを採用しており、一般的に **Public**、**User**、**Admin**、**Root** の4段階があります。

## 認証方式（いずれか1つを選択）

### Session

ログインインターフェースからSessionを取得：

- `POST /api/user/login`

### Access Token（推奨）

リクエストヘッダーに含めます：

```text
Authorization: Bearer {token}
```

トークンは「個人設定 - セキュリティ設定 - システムアクセストークン」で生成できます。

## 必須リクエストヘッダー

一部のインターフェースではユーザー識別リクエストヘッダーが必要です：

```text
New-Api-User: {user_id}
```

`{user_id}` は現在ログイン中のユーザーと一致する必要があります。

## 権限レベル

- **Public**: 認証不要
- **User**: ログインまたはAccess Tokenが必要
- **Admin**: 管理者権限が必要
- **Root**: 最高権限
