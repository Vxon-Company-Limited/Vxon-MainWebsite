<Callout type="info" title="プロジェクト紹介">
  Droid CLIは、Factory AIが開発したコマンドラインツールで、AIソフトウェアエンジニアリングエージェントとして動作するよう設計されています。ターミナルを通じてさまざまな大規模言語モデルとやり取りし、コードの構築、デバッグ、リファクタリング、さらには完全なアプリケーションの作成が可能です。

  - 公式ホームページ：[https://factory.ai/product/cli](https://factory.ai/product/cli)
  - 公式ドキュメント：[https://docs.factory.ai/cli/getting-started/quickstart](https://docs.factory.ai/cli/getting-started/quickstart)
</Callout>

## AIモデル設定方法

### Windowsグラフィカルガイド

#### 1. ターミナルを開く

![windows_open_terminal](/assets/factory_droid_cli/windows_open_terminal.png)

#### 2. Factory Droid CLIのインストール

公式ワンクリックインストールコマンド：

<Callout type="info" title="ワンクリックインストールコマンド">
  ```powershell
  irm https://app.factory.ai/cli/windows | iex
  ```
</Callout>

![windows-install](/assets/factory_droid_cli/windows_install_droid.webp)

#### 3. 設定ファイルの変更

Droid CLIでサードパーティAPIを使用するには、設定ファイルの変更が必要です。

![windows-configure.webp](/assets/factory_droid_cli/factory_cli_setup_windows.png)

<Callout type="info" title="環境変数の変更">
  ```powershell
  iex (irm 'https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/factory-cli-setup.ps1')
  ```
</Callout>

#### 4. Droid CLIの使用開始

Droid CLIを使い始めましょう！

<Callout type="info" title="Droid CLIの起動">
  Droid CLIを直接起動：

  ```bash
  droid
  ```

  特定のプロジェクトで使用する場合：

  ```bash
  # プロジェクトディレクトリに移動
  cd C:\path\to\your\project

  # Droid CLIを起動
  droid
  ```

  Enterを押してDroid CLIを起動してください。
</Callout>

Droid CLIは使用前に公式アカウント（無料）へのログインが必要です。

#### 5. Windowsのよくある問題の解決

<Callout type="info" title='インストール時に「permission denied」エラーが表示される場合'>
  これは通常、権限の問題です。以下の解決策をお試しください：

  - PowerShellを管理者として実行
  - または`npm`をユーザーディレクトリを使用するよう設定：`npm config set prefix %APPDATA%\npm`
</Callout>

<Callout type="info" title="PowerShell実行ポリシーエラー">
  実行ポリシーの制限に遭遇した場合は、以下を実行してください：

  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  ```
</Callout>

### macOS/Linuxグラフィカルガイド

#### 1. Droid CLIのインストール

<Callout type="info" title="Droid CLIのインストール">
  ターミナルを開いて以下のコマンドを実行してください：

  ```bash
  curl -fsSL https://app.factory.ai/cli | sh
  ```
</Callout>

![macos-open-terminal](/assets/factory_droid_cli/macos_install_droid.webp)

![macos-img-02.webp](/assets/factory_droid_cli/macos_install_droid_2.webp)

インストールプロンプトに従って環境変数を変更してください（インストールプロンプトのコードを直接コピー）：

Linuxの場合は、適宜`~/.bashrc`または`~/.zshrc`を選択してください。

<Callout type="info" title="Droid CLI環境変数（例のみ）">
  ```bash
  echo 'export PATH=/Users/modify_here/.local/bin:$PATH' >> ~/.zshrc
  source ~/.zshrc
  ```
</Callout>

#### 2. 設定ファイルの変更

Droid CLIでサードパーティAPIを使用するには、設定ファイルの変更が必要です。

<Callout type="info" title="ワンクリック設定ファイル変更">
  ```bash
  curl -fsSL https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/factory-cli-setup.sh | bash
  ```
</Callout>

![macos-img-03.webp](/assets/factory_droid_cli/macos_configure.png)

#### 3. Droid CLIの使用開始

Droid CLIを使い始めましょう！

<Callout type="info" title="Droid CLIの起動">
  Droid CLIを直接起動：

  ```bash
  droid
  ```

  特定のプロジェクトで使用する場合：

  ```bash
  # プロジェクトディレクトリに移動
  cd /path/to/your/project

  # Droid CLIを起動
  droid
  ```

  Enterを押してDroid CLIを起動してください。
</Callout>

> Droid CLIは使用前に公式アカウント（無料）へのログインが必要です。
