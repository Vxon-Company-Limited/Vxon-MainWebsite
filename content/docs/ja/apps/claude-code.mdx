## AIモデル設定方法

### Windowsグラフィカルガイド

#### 1. Node.js環境のインストール

Claude Codeの実行にはNode.js環境が必要です。

<Callout type="info" title="Node.js環境のインストール手順">
  - ブラウザを開いてhttps://nodejs.org/にアクセス
  - 「LTS」バージョンをクリックしてダウンロード（長期サポートバージョン推奨）
  - ダウンロード後、.msiファイルをダブルクリック
  - インストールウィザードに従ってインストールを完了、デフォルト設定のまま
</Callout>

<Callout type="warn" title="Windowsの注意事項">
  - CMDの代わりにPowerShellの使用を推奨
  - 権限の問題が発生した場合は、管理者として実行してみてください
  - 一部のウイルス対策ソフトが誤検知する場合があります。例外に追加する必要があるかもしれません
</Callout>

<Callout type="info" title="インストール成功の確認">
  インストール後、PowerShellまたはCMDを開いて以下のコマンドを入力してください：

  ```bash
  node --version
  npm --version
  ```

  バージョン番号が表示されれば、インストールは成功です。
</Callout>

#### 2. Git Bashのインストール

<Callout type="warn" title="Windowsの注意事項">
  Windows環境では、Claude Codeのインストールにはgit Bashが必要です。インストール後、環境変数の設定とClaude Codeの使用は通常のPowerShellまたはCMDで行います。
</Callout>

<Callout type="info" title="Git for Windowsのダウンロードとインストール">
  - https://git-scm.com/downloads/winにアクセス
  - 「Download for Windows」をクリックしてインストーラーをダウンロード
  - ダウンロードした.exeインストールファイルを実行
  - インストール中はデフォルト設定のまま、「Next」をクリックしてインストールを完了
</Callout>

![windows-img-06.webp](/assets/claude_code/windows-img-06.webp)

![windows-img-07.webp](/assets/claude_code/windows-img-07.webp)

![windows-img-08.webp](/assets/claude_code/windows-img-08.webp)

<Callout type="info" title="Git Bashインストールの確認">
  インストール後、Git Bashを開いて以下のコマンドを入力して確認してください：

  ```bash
  git --version
  ```

  バージョン番号が表示されれば、インストールは成功です。
</Callout>

#### 3. Claude Codeのインストール

<Callout type="info" title="Claude Codeのインストール">
  PowerShellを開いて以下のコマンドを実行してください：

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```

  このコマンドは、公式npmリポジトリからClaude Codeの最新バージョンをダウンロードしてインストールします。
</Callout>

![windows-img-09.webp](/assets/claude_code/windows-img-09.webp)

<Callout type="info" title="~/.local/binをPATHに追加（プロンプトが表示された場合のみ）">
  ```powershell
  [Environment]::SetEnvironmentVariable('Path', ([Environment]::GetEnvironmentVariable('Path','User') + ";$HOME\.local\bin"), 'User')
  ```
</Callout>

<Callout type="info" title="Claude Codeインストールの確認">
  インストール後、以下のコマンドを入力してインストールが成功したか確認してください：

  ```bash
  claude --version
  ```

  バージョン番号が表示されれば、おめでとうございます！Claude Codeのインストールが完了しました。
</Callout>

#### 4. 環境変数の設定

<Callout type="info" title="ワンクリック設定コマンド（Windowsシステム）">
  Claude Codeをリレーサービスに接続するには、複数の環境変数を設定する必要があります：
</Callout>

```powershell
iex (irm 'https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/claude-cli-setup.ps1')
```

#### 5. Claude Codeの使用開始

Claude Codeを使い始めましょう！

<Callout type="info" title="Claude Codeの起動">
  PowerShellを開いてClaude Codeを直接起動：

  ```bash
  claude
  ```

  特定のプロジェクトで使用する場合：

  ```bash
  # プロジェクトディレクトリに移動
  cd C:\path\to\your\project

  # Claude Codeを起動
  claude
  ```
</Callout>

### macOSグラフィカルガイド

#### 1. Claude Code CLIのインストール

ターミナルを開く

![macos-img-01.webp](/assets/claude_code/macos-img-01.webp)

<Callout type="info" title="Claude Codeのインストール">
  ターミナルを開いて以下のコマンドを実行してください：

  ```bash
  curl -fsSL https://claude.ai/install.sh | bash
  ```

  オプション：プロンプトが表示されたら提供されたコマンドを実行

  ```bash
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
  ```
</Callout>

![macos-img-02.webp](/assets/claude_code/macos-img-02.webp)

#### 4. macOSのよくある問題

<Callout type="info" title="macOSのセキュリティ設定が実行を妨げる場合">
  システムがClaude Codeの実行を妨げる場合：

  - 「システム環境設定」→「セキュリティとプライバシー」を開く
  - 「このまま開く」または「許可」をクリック
  - またはターミナルで実行：`sudo spctl --master-disable`
</Callout>

#### 4. Linuxのよくある問題

<Callout type="info" title="依存ライブラリの不足">
  一部のLinuxディストリビューションでは追加の依存関係のインストールが必要です：

  ```bash
  # Ubuntu/Debian
  sudo apt install build-essential

  # CentOS/RHEL
  sudo dnf groupinstall "Development Tools"
  ```
</Callout>

<Callout type="info" title="環境変数が反映されない場合">
  以下の点を確認してください：

  - 正しい設定ファイル（`.bashrc`または`.zshrc`）を変更したか確認
  - ターミナルを再起動するか`source ~/.bashrc`を実行
  - 設定を確認：`echo $ANTHROPIC_BASE_URL`
</Callout>
