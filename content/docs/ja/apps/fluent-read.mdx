<Callout type="info">
  🌊 FluentReadは、ネイティブに近い読書体験を提供することに特化したオープンソースのブラウザ翻訳プラグインです。
</Callout>

- プロジェクトアドレス：[https://github.com/Bistutu/FluentRead](https://github.com/Bistutu/FluentRead)

## 🌟 コア機能

### スマート翻訳エンジン

- **マルチエンジン対応**：20以上の翻訳エンジンに対応
- **従来型翻訳**：Microsoft翻訳、Google翻訳、DeepL翻訳など
- **AI大規模モデル**：OpenAI、DeepSeek、Kimi、Ollamaなど
- **カスタムエンジン**：カスタム翻訳サービスの設定に対応

### 没入型リーディング体験

- **バイリンガル対照**：原文と翻訳文を並べて表示し、読みやすさを向上
- **選択翻訳**：任意のテキストを選択して即座に翻訳結果を取得
- **ワンクリックコピー**：翻訳テキストを素早くコピーして読書効率を向上
- **全ページ翻訳**：フローティングボタンでウェブページ全体をワンクリック翻訳、ページ更新不要

### プライバシーとカスタマイズ

- **プライバシー保護**：すべてのデータはローカルに保存、オープンソースで透明なコード
- **高いカスタマイズ性**：さまざまなシナリオのニーズに対応する豊富なカスタマイズオプション
- **完全無料**：オープンソースで無料、非商用プロジェクト

## 🚀 設定方法

### Vxonコンソールから設定をインポート（推奨）

FluentReadプラグインをブラウザにインストールした後、Vxonコンソール -> トークン管理ページを開くと、FluentReadの追加プロンプトが表示されます。

![添加提示](/assets/fluentread/hint.png)

モデルを選択した後、「ワンクリックでFluentReadに入力」をクリックすると、確認ウィンドウがポップアップします。対応する情報が正しいか確認してください。

![确认](/assets/fluentread/confirm.png)

インポートを確認すると、FluentReadのVxon設定が有効になります。

![配置结果](/assets/fluentread/fluentread.png)

### FluentReadで手動設定

![手动配置](/assets/fluentread/configuration.png)

| 設定項目  | 内容                                 |
| ------------------- | --------------------------------------- |
| 翻訳サービス | Vxon                                  |
| アクセストークン        | Vxonキー                              |
| Vxonエンドポイント     | Vxonデプロイアドレス（/v1なし） |
| モデル               | リストから選択、またはカスタムモデル       |
| カスタムモデル        | モデル名                              |
