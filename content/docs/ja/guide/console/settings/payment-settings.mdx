## 対応決済ゲートウェイ

- **EPay**
  - 必須フィールド：`APIアドレス`、`加盟店ID (PID)`、`加盟店キー (KEY)`
  - プラットフォームのコールバックパラメータには署名が含まれており、システムが検証して自動的に入金します。
- **Stripe（オプション）**
  - 必須フィールド：`API Key` `WebHook Signing Secret` `Product Price ID`

## EPayとは

`EPay`は「サードパーティ集約決済ゲートウェイ/インターフェース」モデルの総称であり、特定のウェブサイトや企業を指すものではありません。商用の集約決済サービスや、「EPayプロトコルスタイル」に従った自作/オープンソースのゲートウェイ実装を指すことがあります。

- **コア機能**：WeChat Pay、Alipay、銀行カードなどのチャネルを集約し、加盟店に統一された注文作成、署名検証、コールバックインターフェースを提供します。
- **コンプライアンスに関する注意**：ゲートウェイ自体はライセンスを持つ決済機関と同等ではありません。資金の清算、決済、コンプライアンスは、統合されたライセンスチャネルに依存します。現地の規制およびリスク管理要件を遵守してください。

## チャージ方法設定テンプレート

「チャージ方法」では、以下の構造に従って設定できます：

```json
[
  {
    "color": "rgba(var(--semi-blue-5), 1)",
    "name": "支付宝",
    "type": "alipay"
  },
  {
    "color": "rgba(var(--semi-green-5), 1)",
    "name": "微信",
    "type": "wxpay"
  },
  {
    "color": "rgba(var(--semi-green-5), 1)",
    "name": "Stripe",
    "type": "stripe",
    "min_topup": "50"
  },
  {
    "name": "自定义1",
    "color": "black",
    "type": "custom1",
    "min_topup": "50"
  }
]
```

### フィールド説明

- name：表示テキスト。「支払い方法を選択」ボタンに表示されます（例：「Alipay/WeChat/Stripe/Custom1」）。
- color：ボタン/バッジのテーマカラーまたはボーダーカラー。任意のCSS色値に対応しており、既存のデザイントークンの使用を推奨します（例：`rgba(var(--semi-blue-5), 1)`）。
- type：チャネル識別子。バックエンドのルーティングと注文作成に使用されます。
  - `stripe` → Stripeゲートウェイを使用。
  - その他（例：`alipay`、`wxpay`、`custom1`など） → EPayスタイルのゲートウェイを使用し、この値をチャネルパラメータとして渡します。
  - 詳細なロジックはバックエンドコントローラー `controller/topup.go` を参照してください（参考：[controller/topup.go](https://github.com/Vxon/vxon/blob/main/controller/topup.go)）。
- min_topup：最低チャージ金額（単位はページの通貨と一致）。入力金額がこの値未満の場合、ページに「この支払い方法の最低チャージ金額はXです」と表示され、支払いの開始が制限されます。バックエンドでも検証が行われます。
- 順序：配列の順序に従って左から右にレンダリングされます。

## チャージ金額設定

### カスタムチャージ金額オプション

ユーザーが選択できるチャージ金額オプションを設定します。例：

```json
[10, 20, 50, 100, 200, 500]
```

これらの値は「チャージ額を選択」エリアに表示され、ユーザーは直接クリックして対応するチャージ金額を選択できます。

### チャージ金額割引設定

異なるチャージ金額に対応する割引を設定します。キーはチャージ金額、値は割引率です。例：

```json
{
  "100": 0.95,
  "200": 0.9,
  "500": 0.85
}
```

- キー：チャージ金額（文字列形式）
- 値：割引率（0〜1の小数。例：0.95は価格の95%、つまり5%割引を意味します）
- システムは設定に基づいて実際の支払い金額と節約額を自動的に計算します。
- 詳細な実装ロジックはバックエンドコントローラー [controller/topup.go](https://github.com/Vxon/vxon/blob/main/controller/topup.go) を参照してください
