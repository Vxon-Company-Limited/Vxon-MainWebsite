  - 官方文件：[https://docs.factory.ai/cli/getting-started/quickstart](https://docs.factory.ai/cli/getting-started/quickstart)
</Callout>

## AI 模型配置方法

### Windows 端圖文指引

#### 1.開啟終端

![windows_open_terminal](/assets/factory_droid_cli/windows_open_terminal.png)

#### 2.安裝 Factory Droid CLI

官方一鍵安裝命令：

<Callout type="info" title="一鍵安裝命令">
  ```powershell
  irm https://app.factory.ai/cli/windows | iex
  ```
</Callout>

![windows-install](/assets/factory_droid_cli/windows_install_droid.webp)

#### 3.修改配置檔案

Droid CLI 使用第三方 API 需要修改配置檔案。

![windows-configure.webp](/assets/factory_droid_cli/factory_cli_setup_windows.png)

<Callout type="info" title="修改環境變數">
  ```powershell
  iex (irm 'https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/factory-cli-setup.ps1')
  ```
</Callout>

#### 4.開始使用 Droid CLI

現在你可以開始使用 Droid CLI 了！

<Callout type="info" title="啟動 Droid CLI">
  直接啟動 Droid CLI：

  ```bash
  droid
  ```

  在特定專案中使用：

  ```bash
  # 進入你的專案目錄
  cd C:\path\to\your\project

  # 啟動 Droid CLI
  droid
  ```

  按 Enter 啟動 Droid CLI。
</Callout>

Droid CLI 要求使用者登入官方賬號（免費）後才能使用。

#### 5.Windows 常見問題解決

<Callout type="info" title="安裝時提示 permission denied 錯誤">
  這通常是許可權問題，嘗試以下解決方法：

  - 以管理員身份執行 PowerShell
  - 或者配置 `npm` 使用使用者目錄：`npm config set prefix %APPDATA%\npm`
</Callout>

<Callout type="info" title="PowerShell 執行策略錯誤">
  如果遇到執行策略限制，執行：

  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  ```
</Callout>

### macOS/Linux 端圖文指引

#### 1.安裝 Droid CLI

<Callout type="info" title="安裝 Droid CLI">
  開啟終端，執行以下命令：

  ```bash
  curl -fsSL https://app.factory.ai/cli | sh
  ```
</Callout>

![macos-open-terminal](/assets/factory_droid_cli/macos_install_droid.webp)

![macos-img-02.webp](/assets/factory_droid_cli/macos_install_droid_2.webp)

按照安裝提示修改環境變數（直接複製安裝提示程式碼）：

Linux 視情況選擇 `~/.bashrc` 或 `~/.zshrc`

<Callout type="info" title="Droid CLI 環境變數 (僅作示例)">
  ```bash
  echo 'export PATH=/Users/修改此處/.local/bin:$PATH' >> ~/.zshrc
  source ~/.zshrc
  ```
</Callout>

#### 2.修改配置檔案

Droid CLI 使用第三方 API 需要修改配置檔案。

<Callout type="info" title="一鍵修改配置檔案">
  ```bash
  curl -fsSL https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/factory-cli-setup.sh | bash
  ```
</Callout>

![macos-img-03.webp](/assets/factory_droid_cli/macos_configure.png)

#### 3.開始使用 Droid CLI

現在你可以開始使用 Droid CLI 了！

<Callout type="info" title="啟動 Droid CLI">
  直接啟動 Droid CLI：

  ```bash
  droid
  ```

  在特定專案中使用：

  ```bash
  # 進入你的專案目錄
  cd /path/to/your/project

  # 啟動 Droid CLI
  droid
  ```

  按 Enter 啟動 Droid CLI。
</Callout>

> Droid CLI 要求使用者登入官方賬號（免費）後才能使用。
