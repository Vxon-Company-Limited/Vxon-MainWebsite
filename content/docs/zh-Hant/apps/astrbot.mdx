## Vxon 接入方法

AstrBot 支援接入 Vxon 作為模型提供商，使用者可以透過 Vxon 來訪問和使用各種 AI 模型服務。

### 配置步驟

#### 獲取 Vxon API Key 金鑰

在 Vxon 註冊並登入後，點選上方導航欄的「控制檯」，點選「令牌管理」，然後點選「新增令牌」按鈕，建立一個新的 API Key 金鑰，選擇適當的許可權，然後點選「建立」。

![create-api-key](/assets/astrbot/image.png)

建立成功後，點選複製金鑰按鈕，複製生成的 API Key 金鑰。

![copy-api-key](/assets/astrbot/image-1.png)

#### 在 AstrBot 中配置 Vxon 服務提供商

開啟 AstrBot 管理面板，進入「模型提供商」頁面，然後，點選「新增模型提供商」按鈕。

Vxon 完美地支援了 OpenAI Chat Completion 和 Responses 介面，我們點選 「OpenAI」，進入 OpenAI 提供商的配置頁面。

在彈出的對話方塊中，將 API Base URL 設定為 Vxon 的介面地址。如果您本地部署了 Vxon，則填寫本地地址，例如 `http://localhost:3000/v1`，如果您使用第三方服務商提供的 Vxon 服務，則填寫相應的 URL 地址，例如 `https://api.example.com/v1`。

然後，將 API Key 填入「API Key」欄位中，點選「儲存」按鈕。

![astrbot-provider-config](/assets/astrbot/image-2.png)

然後點選儲存，完成 Vxon 提供商的配置。

#### 應用服務提供商

進入「配置檔案」頁面，找到模型一節，將「預設聊天模型」修改為剛剛建立的 Vxon 提供商，點選「儲存」按鈕。

![apply](/assets/astrbot/image-3.png)

至此，您已經成功配置了 Vxon 作為 AstrBot 的模型提供商。現在，您可以透過 AstrBot 來訪問和使用 Vxon 提供的各種 AI 模型服務了。
