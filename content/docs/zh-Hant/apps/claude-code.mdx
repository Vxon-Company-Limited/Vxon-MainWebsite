|                    | 可配置執行在SDK或GitHub Actions中，靈活適配不同需求          |

|                    | 程式碼問題修復與最佳化流程，從分析問題到提交PR                   |

## AI 模型配置方法

### Windows 端圖文指引

#### 1.安裝 Node.js 環境

Claude Code 需要 Node.js 環境才能執行。

<Callout type="info" title="Node.js 環境安裝步驟">
  - 開啟瀏覽器訪問 https://nodejs.org/
  - 點選 "LTS"版本進行下載（推薦長期支援版本）
  - 下載完成後雙擊 .msi 檔案
  - 按照安裝嚮導完成安裝，保持預設設定即可
</Callout>

<Callout type="warn" title="Windows 注意事項">
  - 建議使用 PowerShell 而不是 CMD
  - 如果遇到許可權問題，嘗試以管理員身份執行
  - 某些防毒軟體可能會誤報，需要新增白名單
</Callout>

<Callout type="info" title="驗證安裝是否成功">
  安裝完成後，開啟 PowerShell 或 CMD，輸入以下命令：

  ```bash
  node --version
  npm --version
  ```

  如果顯示版本號，說明安裝成功。
</Callout>

#### 2.安裝 Git Bash

<Callout type="warn" title="Windows 注意事項">
  Windows 環境下需要使用 Git Bash 安裝 Claude code。安裝完成後，環境變數設定和使用 Claude Code 仍然在普通的 PowerShell 或 CMD 中進行。
</Callout>

<Callout type="info" title="下載並安裝 Git for Windows">
  - 訪問 https://git-scm.com/downloads/win
  - 點選 "Download for Windows" 下載安裝包
  - 執行下載的 .exe 安裝檔案
  - 在安裝過程中保持預設設定，直接點選 "Next" 完成安裝
</Callout>

![windows-img-06.webp](/assets/claude_code/windows-img-06.webp)

![windows-img-07.webp](/assets/claude_code/windows-img-07.webp)

![windows-img-08.webp](/assets/claude_code/windows-img-08.webp)

<Callout type="info" title="驗證 Git Bash 安裝">
  安裝完成後，開啟 Git Bash，輸入以下命令驗證：

  ```bash
  git --version
  ```

  如果顯示版本號，說明安裝成功。
</Callout>

#### 3.安裝 Claude Code

<Callout type="info" title="安裝 Claude Code">
  開啟 PowerShell，執行以下命令：

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```

  這個命令會從 npm 官方倉庫下載並安裝最新版本的 Claude Code。
</Callout>

![windows-img-09.webp](/assets/claude_code/windows-img-09.webp)

<Callout type="info" title="將 ~/.local/bin 加入 PATH（僅當提示要求時）">
  ```powershell
  [Environment]::SetEnvironmentVariable('Path', ([Environment]::GetEnvironmentVariable('Path','User') + ";$HOME\.local\bin"), 'User')
  ```
</Callout>

<Callout type="info" title="驗證 Claude Code 安裝">
  安裝完成後，輸入以下命令檢查是否安裝成功：

  ```bash
  claude --version
  ```

  如果顯示版本號，恭喜你！Claude Code 已經成功安裝了。
</Callout>

#### 4.設定環境變數

<Callout type="info" title="一鍵設定命令 (Windows 系統)">
  為了讓 Claude Code 連線到你的中轉服務，需要設定多個環境變數：
</Callout>

```powershell
iex (irm 'https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/claude-cli-setup.ps1')
```

![windows-configure](/assets/claude_code/windows_configure.png)

#### 5.開始使用 Claude Code

現在你可以開始使用 Claude Code 了！

<Callout type="info" title="啟動 Claude Code">
  開啟 PowerShell，直接啟動 Claude Code：

  ```bash
  claude
  ```

  在特定專案中使用：

  ```bash
  # 進入你的專案目錄
  cd C:\path\to\your\project

  # 啟動 Claude Code
  claude
  ```
</Callout>

### MacOS 端圖文指引

#### 1.安裝 Claude Code CLI

開啟終端

![macos-img-01.webp](/assets/claude_code/macos-img-01.webp)

<Callout type="info" title="安裝 Claude Code">
  開啟終端，執行以下命令：

  ```bash
  curl -fsSL https://claude.ai/install.sh | bash
  ```

  可選項：出現提示後執行提供的命令

  ```bash
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
  ```
</Callout>

![macos-img-02.webp](/assets/claude_code/macos-img-02.webp)

<Callout type="info" title="一鍵設定 Claude Code 環境變數">
  輸入命令：

  ```bash
  curl -fsSL https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/claude-cli-setup.sh | bash
  ```
</Callout>

![macos-configure](/assets/claude_code/macos_configure.png)

<Callout type="info" title="驗證 Claude Code 安裝">
  安裝完成後，輸入以下命令檢查是否安裝成功：

  ```bash
  claude --version
  ```

  如果顯示版本號，恭喜你！Claude Code 已經成功安裝了。
</Callout>

#### 3.開始使用 Claude Code

#### 4.macOS 常見問題解決

<Callout type="info" title="macOS 安全設定阻止執行">
  如果系統阻止執行 Claude Code：

  - 開啟"系統偏好設定" → "安全性與隱私"
  - 點選"仍要開啟"或"允許"
  - 或者在 Terminal 中執行：`sudo spctl --master-disable`
</Callout>

#### 4.Linux 常見問題解決

<Callout type="info" title="缺少依賴庫">
  某些 Linux 發行版需要安裝額外依賴：

  ```bash
  # Ubuntu/Debian
  sudo apt install build-essential

  # CentOS/RHEL
  sudo dnf groupinstall "Development Tools"
  ```
</Callout>

<Callout type="info" title="環境變數不生效">
  檢查以下幾點：

  - 確認修改了正確的配置檔案（`.bashrc` 或 `.zshrc`）
  - 重新啟動終端或執行 `source ~/.bashrc`
  - 驗證設定：`echo $ANTHROPIC_BASE_URL`
</Callout>
