## 接入 Vxon

LangBot 支援接入本地部署的 Vxon 和第三方使用 Vxon 搭建的 Vxon 服務。

### 使用方式

1.  從 Vxon 中獲取 API key
    ![獲取 API key](/assets/langbot/get_api_key.png)

        若是本地部署的 Vxon 請自行配置 API 地址（可參考[容器網路連線](https://docs.langbot.app/zh/workshop/network-details.html)），若使用第三方 Vxon 服務，可在頁面上覆制地址。注意，地址後需要新增`/v1`。

2.  在 LangBot 中新增模型，選擇使用 Vxon 供應商，填寫對應的 API key 和 API 地址
    ![新增 Vxon 模型](/assets/langbot/add_vxon_model.png)

3.  在流水線中選擇使用模型

    ![選擇模型](/assets/langbot/select_model.png)

4.  在對話除錯中對話或與繫結至流水線的機器人對話即可使用

    ![對話](/assets/langbot/debug_chat.png)

    ![微信對話](/assets/langbot/wechat.png)

    部署配置機器人請參考[部署機器人](https://docs.langbot.app/zh/deploy/platforms/readme.html)。

### 使用 LangBot 知識庫

LangBot 支援使用 Vxon 的嵌入模型，並將其作為知識庫的向量模型。

1. 在 LangBot 中新增嵌入模型，選擇使用 Vxon 供應商
   ![新增嵌入模型](/assets/langbot/add_embedding_model.png)

2. 在新建知識庫時選用嵌入模型
   ![使用嵌入模型](/assets/langbot/use_embedding_model.png)

更多使用方式請檢視 LangBot 官方文件：[https://docs.langbot.app](https://docs.langbot.app/)
