---
title: 環境變數配置指南
---

本文件提供了Vxon支援的所有環境變數及其配置說明。您可以透過設定這些環境變數來自定義系統的行為。

<Callout type="info" title="提示">
  Vxon 支援從 `.env` 檔案中讀取環境變數，請參照 `.env.example`
  檔案，使用時請將其重新命名為 `.env`。
</Callout>

## 基本配置

| 環境變數 | 說明         | 預設值          | 示例                  |
| -------- | ------------ | --------------- | --------------------- |
| `PORT`   | 服務監聽埠 | `3000`          | `PORT=8080`           |
| `TZ`     | 時區設定     | -               | `TZ=America/New_York` |
| `VERSION`| 覆蓋執行版本號 | -              | `VERSION=1.2.3`       |

## 資料庫配置

| 環境變數                | 說明                       | 預設值                   | 示例                                                                                                                             |
| ----------------------- | -------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `SQL_DSN`               | 資料庫連線字串           | SQLite (`one-api.db`) | MySQL: `SQL_DSN=root:123456@tcp(localhost:3306)/vxon` \| PostgreSQL: `SQL_DSN=postgresql://root:123456@postgres:5432/vxon` |
| `SQL_MAX_IDLE_CONNS`    | 空閒連線池最大連線數       | `100`                    | `SQL_MAX_IDLE_CONNS=50`                                                                                                          |
| `SQL_MAX_OPEN_CONNS`    | 連線池最大開啟連線數       | `1000`                   | `SQL_MAX_OPEN_CONNS=500`                                                                                                         |
| `SQL_MAX_LIFETIME`      | 連線最大生命週期(秒)       | `60`                     | `SQL_MAX_LIFETIME=120`                                                                                                          |
| `LOG_SQL_DSN`           | 日誌表獨立資料庫連線字串 | -                        | `LOG_SQL_DSN=root:123456@tcp(localhost:3306)/oneapi_logs`                                                                        |
| `SQLITE_PATH`           | SQLite資料庫路徑           | `one-api.db`             | `SQLITE_PATH=/var/lib/vxon/vxon.db`                                                                                        |

## 多節點與安全配置

| 環境變數                    | 說明                         | 預設值   | 示例                                        |
| --------------------------- | ---------------------------- | -------- | ------------------------------------------- |
| `SESSION_SECRET`            | 會話金鑰(多機部署必須)       | -        | `SESSION_SECRET=your_session_secret`        |
| `CRYPTO_SECRET`             | 加密金鑰(加密資料庫內容，預設回退到SESSION_SECRET) | -        | `CRYPTO_SECRET=your_crypto_secret`          |
| `FRONTEND_BASE_URL`         | 前端基礎URL（從節點使用，將未匹配路由重定向到此地址） | -        | `FRONTEND_BASE_URL=https://<your-vxon-domain>` |
| `NODE_TYPE`                 | 節點型別                     | `master` | `NODE_TYPE=slave`                           |
| `TLS_INSECURE_SKIP_VERIFY`  | 全域性跳過TLS證書驗證         | `false`  | `TLS_INSECURE_SKIP_VERIFY=true`             |
| `TRUSTED_REDIRECT_DOMAINS`  | 受信任的重定向域名列表(逗號分隔) | -    | `TRUSTED_REDIRECT_DOMAINS=example.com,api.example.com` |

<Callout type="warn" title="SESSION_SECRET 注意事項">
  `SESSION_SECRET` 不可設定為 `random_string`，否則程式將拒絕啟動。多機部署時所有節點必須使用相同的金鑰。
</Callout>

<Callout type="info" title="叢集部署">

</Callout>

## 中繼與代理配置

| 環境變數                       | 說明                                        | 預設值 | 示例                             |
| ------------------------------ | ------------------------------------------- | ------ | -------------------------------- |
| `RELAY_TIMEOUT`                | 中繼請求超時時間(秒)，0為不限               | `0`    | `RELAY_TIMEOUT=60`               |
| `STREAMING_TIMEOUT`            | 流式一次回覆的超時時間(秒)                  | `300`  | `STREAMING_TIMEOUT=120`          |
| `RELAY_MAX_IDLE_CONNS`         | 中繼HTTP客戶端池最大空閒連線數              | `500`  | `RELAY_MAX_IDLE_CONNS=1000`      |
| `RELAY_MAX_IDLE_CONNS_PER_HOST`| 中繼HTTP客戶端池每主機最大空閒連線數        | `100`  | `RELAY_MAX_IDLE_CONNS_PER_HOST=200` |
| `MAX_FILE_DOWNLOAD_MB`         | 最大檔案下載大小(MB)                        | `64`   | `MAX_FILE_DOWNLOAD_MB=128`       |
| `MAX_REQUEST_BODY_MB`          | 最大請求體大小(MB，解壓後計；防止zip bomb/OOM) | `128`  | `MAX_REQUEST_BODY_MB=256`        |
| `STREAM_SCANNER_MAX_BUFFER_MB` | SSE流掃描緩衝區最大大小(MB)                 | `64`   | `STREAM_SCANNER_MAX_BUFFER_MB=128` |

<Callout type="warn" title="RELAY_TIMEOUT 設定警告">
  設定 `RELAY_TIMEOUT` 環境變數時請謹慎，如果設定過短可能導致以下問題：
</Callout>

    - 上游API已經完成請求並計費，但本地因超時而未完成計費

    - 造成計費不同步，可能導致系統虧損

    - 建議不設定，除非您知道自己在做什麼

## 多機部署示例

在多機部署場景中，必須設定以下環境變數：

### 主節點配置

```bash
# 資料庫配置 - 使用遠端資料庫
SQL_DSN=root:password@tcp(db-server:3306)/oneapi

# 安全配置
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis快取配置
REDIS_CONN_STRING=redis://default:password@redis-server:6379
```

### 從節點配置

```bash
# 資料庫配置 - 使用相同的遠端資料庫
SQL_DSN=root:password@tcp(db-server:3306)/oneapi

# 安全配置 - 與主節點使用相同的金鑰
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis快取配置 - 與主節點使用相同的Redis
REDIS_CONN_STRING=redis://default:password@redis-server:6379

# 節點型別設定
NODE_TYPE=slave

# 可選：前端基礎URL
# FRONTEND_BASE_URL=https://<your-vxon-domain>

# 可選：同步頻率
SYNC_FREQUENCY=60
```

<Callout type="info" title="完整叢集配置">
  這只是基本的多節點配置示例。完整的叢集部署配置、架構說明和最佳實踐，請參考[叢集部署指南](/zh-Hant/docs/installation/deployment-methods/cluster-deployment)。
</Callout>

## Docker Compose中的環境變數示例

下面是一個在Docker Compose配置檔案中設定環境變數的簡要示例:

```yaml
services:
  vxon:
    image: vxon/vxon:latest
    environment:
      - TZ=Asia/Shanghai
      - SQL_DSN=root:123456@tcp(mysql:3306)/oneapi
      - REDIS_CONN_STRING=redis://default:redispw@redis:6379
      - SESSION_SECRET=your_unique_session_secret
      - CRYPTO_SECRET=your_unique_crypto_secret
      - MEMORY_CACHE_ENABLED=true
      - GENERATE_DEFAULT_TOKEN=true
      - STREAMING_TIMEOUT=120
      - CHANNEL_UPDATE_FREQUENCY=1440
```

有關完整的Docker Compose配置，包括更多環境變數設定選項，請參考[Docker Compose配置說明](/zh-Hant/docs/installation/config-maintenance/docker-compose-yml)文件。
