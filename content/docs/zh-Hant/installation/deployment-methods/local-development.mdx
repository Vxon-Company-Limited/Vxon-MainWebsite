title: 本地開發部署
---

本文件提供了在本地環境中設定和開發 Vxon 專案的詳細步驟，適合希望參與專案開發或進行功能定製的開發者。

## 開發環境要求

在開始本地開發之前，請確保您的系統已安裝以下軟體：

- **Go** 1.21 或更高版本（後端開發）
- **Node.js** 18 或更高版本（前端開發）
- **Bun** 最新版本（推薦的包管理器，比 npm/yarn 快 25 倍）
- **Git**（版本控制）
- **MySQL**（可選，預設使用 SQLite）
- **Redis**（可選，用於提升效能）
- **Visual Studio Code** 或其他程式碼編輯器

<Callout type="info" title="關於 Bun">
  Bun是一個超快的JavaScript包管理器、測試執行器和bundler。相比傳統的npm或yarn，Bun的安裝速度快25倍，是2024年最推薦的JavaScript包管理工具。
</Callout>

## 克隆專案

首先，從 GitHub 克隆 Vxon 倉庫到本地：

```bash
git clone https://github.com/Vxon/vxon.git
cd vxon
```

## 後端開發設定

### 安裝 Go 依賴

```bash
go mod download
```

### 配置開發環境

Vxon 支援透過 `.env` 檔案配置環境變數。建立 `.env` 檔案（可從 `.env.example` 複製）：

```bash
cp .env.example .env
```

編輯 `.env` 檔案，根據需要修改配置。以下是開發環境中常用的配置：

```bash
PORT=3000
SQL_DSN=root:password@tcp(localhost:3306)/vxon   # 如使用MySQL，取消註釋並修改
# REDIS_CONN_STRING=redis://localhost:6379         # 如使用Redis，取消註釋並修改
```

<Callout type="info" title="提示">
  如果不配置 `SQL_DSN`，系統將預設使用 SQLite 資料庫，儲存在 `one-api.db`
  檔案中。
</Callout>

### 執行後端服務

```bash
# 直接執行
go run main.go

# 或者編譯後執行
go build -o vxon
./vxon
```

服務預設執行在 `http://localhost:3000`

## 前端開發設定

Vxon 的前端程式碼位於 `web` 目錄中，使用 React 和 [semi design 元件庫](https://semi.design/zh-CN) 開發。

### 安裝 Bun（推薦）

如果還沒有安裝 Bun，請使用以下命令安裝：

**macOS/Linux:**

```bash
curl -fsSL https://bun.sh/install | bash
```

**Windows（使用 WSL）:**

```bash
curl -fsSL https://bun.sh/install | bash
```

**macOS（使用 Homebrew）:**

```bash
brew tap oven-sh/bun
brew install bun
```

安裝完成後，重啟終端或執行 `source ~/.bashrc`（或 `~/.zshrc`）使 Bun 命令生效。

### 安裝前端依賴

```bash
cd web
bun install   # 使用 bun 安裝前端依賴
```

### 執行開發伺服器

```bash
bun run dev   # 使用 bun 執行開發伺服器
```

前端開發伺服器預設執行在 `http://localhost:5173`，並配置了代理，會將 API 請求轉發到後端服務。

### 構建前端資源

```bash
bun run build   # 使用 bun 構建前端資源
```

構建後的檔案會生成到 `web/dist` 目錄，後端服務會自動載入這些靜態資源。

7. **建立拉取請求**：在 GitHub 上建立 PR，描述您的更改

## 除錯技巧

### 後端除錯

1. **檢視日誌**：

   ```bash
   go run main.go --log-dir ./logs
   ```

2. **使用 Delve 進行除錯**：
   ```bash
   go install github.com/go-delve/delve/cmd/dlv@latest
   dlv debug main.go
   ```

### 前端除錯

1. **使用 Chrome DevTools**：
   - 開啟 Chrome 開發者工具 (F12)
   - 檢視 Console 和 Network 標籤頁

2. **React 開發者工具**：
   - 在 Chrome 中安裝 React Developer Tools 擴充套件
   - 使用它檢查元件結構和狀態
