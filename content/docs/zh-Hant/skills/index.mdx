## 概述

**Skills** 是一種輕量級擴充套件協議，讓 AI 編輯器（如 Claude Code、Codex、OpenClaw（龍蝦）、Cursor、Windsurf 等）能夠在編碼環境內直接與 Vxon 互動，無需切換到瀏覽器或管理面板。

Vxon Skills 現已支援在 Claude Code、Codex、OpenClaw（龍蝦）等工具中直接執行查詢模型、管理令牌、檢視餘額，以及提問 Vxon 使用問題等操作。

Vxon 目前提供以下 Skills：

## 支援的 AI 編輯器

所有 Skills 均可在以下 AI 編碼工具中使用：

| AI 編輯器 / 編碼助手 | 型別 | 備註 |
|----------------------|------|------|
| **Claude Code** | 終端 AI 程式設計助手 | Anthropic 官方 CLI |
| **OpenClaw** | 自託管 AI 助手平臺 | 支援 Skills，可在對話中直接呼叫 `/vxon` 指令 |
| **Cursor** | AI 原生程式碼編輯器 | 基於 VS Code |
| **Windsurf** | AI 程式碼編輯器 | Codeium 出品 |
| **Cline** | VS Code AI 擴充套件 | 開源 AI 編碼代理 |
| **Codex CLI** | 終端 AI 程式設計助手 | OpenAI 官方 CLI |

> 任何支援 Skills 協議的 AI 工具都可以使用 Vxon Skills。
