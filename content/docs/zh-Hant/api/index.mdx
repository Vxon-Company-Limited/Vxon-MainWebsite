## 概述

Vxon 提供完整的 RESTful API 介面，分為 **AI 模型介面** 和 **管理介面** 兩大類。您可以透過這些介面實現 AI 能力呼叫和系統管理功能。

<Callout title="線上除錯">
  您可以訪問 [Apifox 操練場](https://apifox.vxon.ai/) 線上測試和除錯 API 介面，或瀏覽下方的 API 文件。
</Callout>
