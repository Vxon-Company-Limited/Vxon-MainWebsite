## 說明

後臺管理介面採用多級鑑權機制，常見為：**公開**、**使用者**、**管理員**、**Root**。

## 認證方式（二選一）

### Session

透過登入介面獲取 Session：

- `POST /api/user/login`

### Access Token（推薦）

在請求頭中攜帶：

```text
Authorization: Bearer {token}
```

Token 可在「個人設定 - 安全設定 - 系統訪問令牌」中生成。

## 必需請求頭

部分介面要求攜帶使用者標識請求頭：

```text
New-Api-User: {user_id}
```

其中 `{user_id}` 必須與當前登入使用者匹配。

## 許可權級別

- **公開（Public）**：無需鑑權
- **使用者（User）**：需要登入或 Access Token
- **管理員（Admin）**：需要管理員許可權
- **Root**：最高許可權
