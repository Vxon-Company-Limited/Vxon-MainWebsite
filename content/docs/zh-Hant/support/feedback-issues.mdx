---
title: 問題反饋
---

我們非常重視您的反饋，它們對專案的改進至關重要。如果您在使用過程中遇到任何問題，請透過GitHub Issues向我們反饋。

## 📝 如何提交問題

請訪問我們的GitHub Issues頁面：[Vxon Issues](https://github.com/Vxon/vxon/issues)

<Callout type="info" title="提交問題前的檢查">
  在提交新的issue之前，建議您：
</Callout>

    1. 搜尋是否已經存在類似的問題
    2. 確保使用的是最新版本
    3. 檢查 [常見問題文件](/zh-Hant/docs/support/faq) 中是否已有相關解答

![feedback-issues](/assets/issues.png)

## 💡 問題反饋模板

### 報告問題的格式

```markdown
**例行檢查**

[//]: # '方框內刪除已有的空格，填 x 號'

- [ ] 我已確認目前沒有類似 issue
- [ ] 我已確認我已升級到最新版本
- [ ] 我已完整檢視過專案 README，尤其是常見問題部分
- [ ] 我理解並願意跟進此 issue，協助測試和提供反饋
- [ ] 我理解並認可上述內容，並理解專案維護者精力有限，**不遵循規則的 issue 可能會被無視或直接關閉**

**問題描述**

**復現步驟**

**預期結果**

**相關截圖**
如果沒有的話，請刪除此節。
```

### 功能請求的格式

```markdown
**例行檢查**

[//]: # '方框內刪除已有的空格，填 x 號'

- [ ] 我已確認目前沒有類似 issue
- [ ] 我已確認我已升級到最新版本
- [ ] 我已完整檢視過專案 README，已確定現有版本無法滿足需求
- [ ] 我理解並願意跟進此 issue，協助測試和提供反饋
- [ ] 我理解並認可上述內容，並理解專案維護者精力有限，**不遵循規則的 issue 可能會被無視或直接關閉**

**功能描述**

**應用場景**
```

<Callout type="warn" title="注意事項">
  - 請嚴格按照模板格式提交issue - 請使用清晰的標題，方便其他使用者搜尋 -
  請及時關注和回覆您提交的issue - 不符合規範的issue可能會被直接關閉 -
  如果問題已解決，請及時關閉issue
</Callout>
