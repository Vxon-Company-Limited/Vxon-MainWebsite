---
title: 特性說明
---

1. 🎨 全新的UI介面（部分介面還待更新）
2. 🌍 多語言支援（待完善）
3. 🎨 新增[Midjourney-Proxy(Plus)](https://github.com/novicezk/midjourney-proxy)介面支援
4. 💰 支援線上充值功能，可在系統設定中設定：
   - [x] 易支付
5. 🔍 支援用key查詢使用額度：
   - 配合專案[neko-api-key-tool](https://github.com/Vxon/neko-api-key-tool)可實現用key查詢使用
6. 📑 分頁支援選擇每頁顯示數量
7. 🔄 支援 SQLite 資料庫儲存，開箱即用，輕量便捷
8. 💵 支援模型按次數收費，可在 系統設定-運營設定 中設定
9. ⚖️ 支援渠道 **加權隨機**
10. 📈 資料看板（控制檯）
11. 🔒 可設定令牌能呼叫的模型
12. 🤖 支援Telegram授權登入：
    1. 系統設定-配置登入註冊-允許透過Telegram登入
    2. 對[@Botfather](https://t.me/botfather)輸入指令/setdomain
    3. 選擇你的bot，然後輸入http(s)://你的網站地址/login
    4. Telegram Bot 名稱是bot username 去掉@後的字串
13. 🎵 新增 [Suno API](https://github.com/Suno-API/Suno-API)介面支援
14. 🔄 支援Rerank模型，目前相容Cohere和Jina，可接入Dify
15. ⚡ **[OpenAI Realtime API](https://platform.openai.com/docs/guides/realtime/integration)** - 支援OpenAI的Realtime API，支援Azure渠道
16. 支援使用路由/chat2link 進入聊天介面
17. 🧠 支援透過模型名稱字尾設定 reasoning effort：
    1. OpenAI o系列模型
       - 新增字尾 `-high` 設定為 high reasoning effort (例如: `o3-mini-high`)
       - 新增字尾 `-medium` 設定為 medium reasoning effort (例如: `o3-mini-medium`)
       - 新增字尾 `-low` 設定為 low reasoning effort (例如: `o3-mini-low`)
    2. Claude 思考模型
       - 新增字尾 `-thinking` 啟用思考模式 (例如: `claude-3-7-sonnet-20250219-thinking`)
18. 🔄 思考轉內容，支援在 `渠道-編輯-渠道額外設定` 中設定 `thinking_to_content` 選項，預設`false`，開啟後會將思考內容 `reasoning_content` 轉換為 `<think>` 標籤拼接到內容中返回。
19. 🔄 模型限流，支援在 `系統設定-速率限制設定` 中設定模型限流，支援設定總請求數限制和成功請求數限制
20. 💰 快取計費支援，開啟後可以在快取命中時按照設定的比例計費：
    1. 在 `系統設定-運營設定` 中設定 提示快取倍率 選項
    2. 在渠道中設定 提示快取倍率，範圍 0-1，例如設定為 0.5 表示快取命中時按照 50% 計費
    3. 支援的渠道：
    - [x] OpenAI
    - [x] Azure
    - [x] DeepSeek
    - [ ] Claude
