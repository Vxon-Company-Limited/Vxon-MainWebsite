---
title: 倍率設定
---

倍率設定是 Vxon 計費系統的核心配置，透過設定不同的倍率可以靈活控制各種模型和使用者組的計費標準。

## 倍率系統概述

Vxon 使用三層倍率體系來計算使用者的配額消耗：

1. 模型倍率（ModelRatio） - 定義不同AI模型的基礎計費倍數
2. 補全倍率（CompletionRatio） - 對輸出token進行額外計費調整
3. 分組倍率（GroupRatio） - 為不同使用者組設定差異化計費倍數

### 配額與倍率的關係

在 Vxon 系統中，倍率是計算配額消耗的關鍵引數。配額是系統內部的計費單位，所有的API呼叫最終都會轉換為配額點數進行扣減。

配額單位轉換：

- 1 美元 = 500,000 配額點數
- 配額點數是系統內部計費的基礎單位
- 使用者的餘額、消費記錄都以配額點數為準

### 配額計算公式

#### 按量計費模型（基於Token消耗）

```
配額消耗 = (輸入token數 + 輸出token數 × 補全倍率) × 模型倍率 × 分組倍率
```

#### 按次計費模型（固定價格）

```
配額消耗 = 模型固定價格 × 分組倍率 × 配額單位(500,000)
```

#### 音訊模型（特殊處理，vxon內部自動處理）

```
配額消耗 = (文字輸入token + 文字輸出token × 補全倍率 + 音訊輸入token × 音訊倍率 + 音訊輸出token × 音訊倍率 × 音訊補全倍率) × 模型倍率 × 分組倍率
```

#### 預消費與後消費機制

Vxon 採用預消費和後消費的雙重計費機制：

1. **預消費階段**：API呼叫前，根據預估token數計算配額消耗並預扣
2. **後消費階段**：API呼叫完成後，根據實際token數重新計算配額消耗
3. **差額調整**：如果實際消耗與預消費不同，系統會自動調整使用者配額餘額

```
預消費配額 = 預估token數 × 模型倍率 × 分組倍率
實際配額 = 實際token數 × 模型倍率 × 分組倍率
配額調整 = 實際配額 - 預消費配額
```

## 模型倍率設定

模型倍率定義了不同AI模型的基礎計費倍數，系統為各種模型預設了預設倍率。

### 常見模型倍率示例

| 模型名稱      | 模型倍率 | 補全倍率 | 官網價格（輸入） | 官網價格（輸出） |
| ------------- | -------- | -------- | ---------------- | ---------------- |
| gpt-4o        | 1.25     | 4        | $2.5/1M Tokens   | $10/1M Tokens    |
| gpt-3.5-turbo | 0.25     | 1.33     | $0.5/1M Tokens   | $1.5/1M Tokens   |
| gpt-4o-mini   | 0.075    | 4        | $0.15/1M Tokens  | $0.6/1M Tokens   |
| o1            | 7.5      | 4        | $15/1M Tokens    | $60/1M Tokens    |

倍率含義說明：

- 模型倍率：相對於基礎計費單位的倍數，反映模型的成本差異
- 補全倍率：輸出token相對於輸入token的計費倍數，反映輸出成本差異
- 倍率越高，消耗的配額越多；倍率越低，消耗的配額越少

### 設定方法

1. JSON格式設定：直接編輯模型倍率JSON配置
2. 視覺化編輯器：透過圖形介面設定倍率

## 補全倍率設定

補全倍率用於對輸出token進行額外計費，主要用於平衡不同模型的輸入輸出成本差異。

### 預設補全倍率

| 模型型別      | 官網價格（輸入） | 官網價格（輸出） | 補全倍率 | 說明            |
| ------------- | ---------------- | ---------------- | -------- | --------------- |
| gpt-4o        | 2.5$/1M Tokens   | 10$/1M Tokens    | 4        | 輸出是輸入的4倍 |
| gpt-3.5-turbo | 0.5$/1M Tokens   | 1$/1M Tokens     | 2        | 輸出是輸入的2倍 |
| gpt-image-1   | 5$/1M Tokens     | 40$/1M Tokens    | 8        | 輸出是輸入的8倍 |
| gpt-4o-mini   | 0.15$/1M Tokens  | 0.6$/1M Tokens   | 4        | 輸出是輸入的4倍 |
| 其他模型      | 1                | 1                | 1        | 輸出是輸入的1倍 |

### 設定說明

- 補全倍率主要影響輸出token的計費
- 設定為1表示輸出token計費與輸入token計費相同
- 大於1表示輸出token計費更高，小於1表示輸出token計費更低

## 分組倍率設定

分組倍率允許為不同使用者組設定差異化的計費倍數，實現靈活的定價策略。

### 分組倍率配置

```json
{
  "vip": 0.5,
  "premium": 0.8,
  "standard": 1.0,
  "trial": 2.0
}
```

### 分組倍率優先順序

1. 使用者專屬倍率：為特定使用者設定的個人倍率
2. 分組倍率：使用者所屬分組的倍率
3. 預設倍率：系統預設倍率（通常為1.0）

## 未設定倍率模型

對於未設定倍率的模型，系統會：

1. 自用模式：使用預設倍率37.5
2. 商業模式：提示"倍率或價格未配置"錯誤
3. 自動檢測：在管理介面顯示未配置的模型

## 常見問題

### Q: 如何為新模型設定倍率？

A: 可以透過視覺化編輯器新增新模型，或直接在JSON配置中新增。建議先設定保守倍率，根據實際使用情況調整。

### Q: 分組倍率如何生效？

A: 分組倍率會與模型倍率相乘，最終影響使用者的配額消耗計算。使用者的實際倍率 = 模型倍率 × 分組倍率。

### Q: 補全倍率的作用是什麼？

A: 補全倍率主要用於平衡輸入輸出token的成本差異。某些模型的輸出成本遠高於輸入成本，需要透過補全倍率進行調整。

### Q: 如何批次設定相似模型的倍率？

A: 可以透過視覺化編輯器進行批次操作，或者直接在JSON配置中批次新增相似模型的倍率設定。

## 配額計算例項

### 示例1：GPT-4 標準使用者對話

場景引數：

- 輸入token：1,000
- 輸出token：500
- 模型倍率：15
- 補全倍率：2
- 分組倍率：1.0（標準使用者）

計算過程：

```
配額消耗 = (1,000 + 500 × 2) × 15 × 1.0
         = (1,000 + 1,000) × 15
         = 2,000 × 15
         = 30,000 配額點數
```

等價美元成本：30,000 ÷ 500,000 = $0.06

### 示例2：GPT-3.5 VIP使用者對話

場景引數：

- 輸入token：2,000
- 輸出token：1,000
- 模型倍率：0.25
- 補全倍率：1.33
- 分組倍率：0.5（VIP使用者50%折扣）

計算過程：

```
配額消耗 = (2,000 + 1,000 × 1.33) × 0.25 × 0.5
         = (2,000 + 1,330) × 0.125
         = 3,330 × 0.125
         = 416.25 配額點數
```

等價美元成本：416.25 ÷ 500,000 = $0.00083

### 示例3：按次計費模型（如Midjourney）

場景引數：

- 模型固定價格：$0.02
- 分組倍率：1.0（標準使用者）
- 配額單位：500,000

計算過程：

```
配額消耗 = 0.02 × 1.0 × 500,000
         = 10,000 配額點數
```

等價美元成本：10,000 ÷ 500,000 = $0.02
