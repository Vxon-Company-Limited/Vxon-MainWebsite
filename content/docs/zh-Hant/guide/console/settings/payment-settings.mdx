## 支援的支付閘道器

- **易支付（EPay）**
  - 必填項：`API 地址`、`商戶 ID（PID）`、`商戶金鑰（KEY）`
  - 平臺回撥引數包含簽名，系統會進行校驗並自動入賬
- **Stripe（可選）**
  - 必填項：`API 金鑰` `WebHook 簽名金鑰` `商品價格 ID`

## 什麼是易支付

`易支付`是對“第三方聚合收款閘道器/介面”模式的泛稱，並非某一傢俱體的網站或公司。既可指商用聚合支付服務，也可指自建/開源、遵循“易支付協議風格”的閘道器實現。

- **核心作用**: 聚合微信支付、支付寶、銀行卡等渠道，向商戶提供統一的下單、簽名校驗與回撥介面。
- **合規提示**: 閘道器本身不等同於持牌支付機構；資金清結算與合規依賴其對接的持牌渠道，請遵循所在地監管與風控要求。

## 充值方式設定模板

在“充值方式”中，可按以下結構配置：

```json
[
  {
    "color": "rgba(var(--semi-blue-5), 1)",
    "name": "支付寶",
    "type": "alipay"
  },
  {
    "color": "rgba(var(--semi-green-5), 1)",
    "name": "微信",
    "type": "wxpay"
  },
  {
    "color": "rgba(var(--semi-green-5), 1)",
    "name": "Stripe",
    "type": "stripe",
    "min_topup": "50"
  },
  {
    "name": "自定義1",
    "color": "black",
    "type": "custom1",
    "min_topup": "50"
  }
]
```

### 欄位說明

- name: 展示文案。顯示在"選擇支付方式"的按鈕上（如"支付寶/微信/Stripe/自定義1"）。
- color: 按鈕/徽標的主題色或邊框色。支援任意 CSS 顏色值，推薦使用現有設計令牌（如 `rgba(var(--semi-blue-5), 1)`）。
- type: 通道標識，用於後端路由與下單。
  - `stripe` → 走 Stripe 閘道器。
  - 其他（如 `alipay`、`wxpay`、`custom1` 等）→ 走易支付風格閘道器，並將該值作為渠道引數透傳。
  - 詳細邏輯見後端控制器 `controller/topup.go`（參考: [controller/topup.go](https://github.com/Vxon/vxon/blob/main/controller/topup.go)）。
- min_topup: 最低充值金額（單位與頁面貨幣一致）。當輸入金額小於該值時，頁面會提示"此支付方式最低充值金額為 X"，並限制發起支付；後端也會進行校驗。
- 排序: 按陣列順序從左到右渲染。

## 充值金額配置

### 自定義充值數量選項

設定使用者可選擇的充值數量選項，例如：

```json
[10, 20, 50, 100, 200, 500]
```

這些數值會顯示在"選擇充值額度"區域，使用者可以直接點選選擇對應的充值金額。

### 充值金額折扣配置

設定不同充值金額對應的折扣，鍵為充值金額，值為折扣率，例如：

```json
{
  "100": 0.95,
  "200": 0.9,
  "500": 0.85
}
```

- 鍵：充值金額（字串格式）
- 值：折扣率（0-1之間的小數，如 0.95 表示 95% 價格，即 5% 折扣）
- 系統會根據配置自動計算實付金額和節省金額
- 詳細實現邏輯見後端控制器 [controller/topup.go](https://github.com/Vxon/vxon/blob/main/controller/topup.go)
