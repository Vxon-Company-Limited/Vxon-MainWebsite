## Descripción general

Vxon proporciona un conjunto completo de interfaces API RESTful, clasificadas en dos tipos principales: **APIs de modelos de IA** y **APIs de gestión**. Puedes usar estas interfaces para invocar capacidades de IA y realizar funciones de gestión del sistema.

<Callout title="Depuración en línea">
  Puedes visitar [Apifox Playground](https://apifox.vxon.ai/) para probar y depurar las interfaces API en línea, o consultar la documentación de API a continuación.
</Callout>
