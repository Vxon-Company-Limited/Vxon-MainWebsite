Sus comentarios son muy valiosos y cruciales para la mejora del proyecto. Si encuentra algún problema durante el uso, repórtelo a través de GitHub Issues.

## 📝 Cómo enviar un issue

Visite nuestra página de GitHub Issues: [Vxon Issues](https://github.com/Vxon/vxon/issues)

<Callout type="info" title="Antes de enviar un issue">
  Antes de enviar un nuevo issue, le recomendamos que:
</Callout>

    1. Busque si ya existe un issue similar
    2. Asegúrese de estar usando la última versión
    3. Verifique si hay respuestas relevantes en el [documento de preguntas frecuentes](/es/docs/support/faq)

```markdown
**例行检查**
```

### Formato para solicitudes de funcionalidades

```markdown
**例行检查**

[//]: # '方框内删除已有的空格，填 x 号'

- [ ] 我已确认目前没有类似 issue
- [ ] 我已确认我已升级到最新版本
- [ ] 我已完整查看过项目 README，已确定现有版本无法满足需求
- [ ] 我理解并愿意跟进此 issue，协助测试和提供反馈
- [ ] 我理解并认可上述内容，并理解项目维护者精力有限，**不遵循规则的 issue 可能会被无视或直接关闭**

**应用场景**
```

<Callout type="warn" title="Notas importantes">
  - Siga estrictamente el formato de la plantilla al enviar issues - Use
  un título claro para facilitar la búsqueda de otros usuarios - Preste
  atención y responda a sus issues enviados de manera oportuna - Los issues
  que no cumplan con las especificaciones pueden cerrarse directamente - Si el issue
  se resuelve, ciérrelo rápidamente
</Callout>
