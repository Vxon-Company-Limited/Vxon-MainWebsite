¡Bienvenido a la comunidad de código abierto de Vxon! Aquí puede intercambiar experiencias y compartir ideas con otros desarrolladores.

## 📜 Reglas del grupo

Para mantener una atmósfera comunitaria positiva, observe las siguientes reglas:

<Callout type="warn" title="Aviso importante">
  La violación de estas reglas puede resultar en la expulsión del grupo de chat. Se solicita a todos los miembros que lean y cumplan cuidadosamente.
</Callout>

1. Los administradores y propietarios del grupo no tienen obligación de proporcionarle soporte técnico. Si tiene preguntas, envíe un [issue](/es/docs/support/feedback-issues)
2. El chat del grupo prohíbe la publicación de cualquier información de venta o compra de cuentas. Los apodos del grupo tienen prohibido contener cualquier guía de compra o información relacionada con compras.
3. Este grupo no vende ningún producto de API. No confíe ni compre productos de API de nadie (incluidos los administradores).
4. Vxon adopta la licencia de código abierto GNU AGPLv3. Se puede usar de forma gratuita siempre que se cumpla con la licencia de código abierto. Para más detalles, consulte [Introducción del proyecto](/es/docs/guide/wiki/basic-concepts/project-introduction)
5. Este proyecto debe usarse en cumplimiento con las leyes y regulaciones pertinentes. Se prohíbe la discusión de cualquier tema ilegal.

<Callout title="Recordatorio amigable">
  Si tiene alguna sugerencia de funcionalidad o comentario sobre errores, se recomienda enviar un issue directamente en GitHub, lo que permite un mejor seguimiento y resolución de problemas.
</Callout>
