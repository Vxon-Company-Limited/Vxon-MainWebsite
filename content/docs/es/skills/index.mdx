## Descripción general

**Skills** son un protocolo de extensión ligero que permite a los editores de IA (como Claude Code, Codex, OpenClaw, Cursor, Windsurf, etc.) interactuar con Vxon directamente desde su entorno de codificación — sin necesidad de navegador ni panel de administración.

Los Skills de Vxon ya funcionan en Claude Code, Codex, OpenClaw y otras herramientas compatibles con Skills para consultas de modelos, gestión de tokens, verificación de saldo y preguntas sobre el uso de Vxon.

Vxon actualmente ofrece los siguientes Skills:

## Editores de IA compatibles

Todos los Skills funcionan con las siguientes herramientas de codificación con IA:

| Editor de IA / Asistente de codificación | Tipo | Notas |
|------------------------------|------|-------|
| **Claude Code** | Asistente de programación de terminal con IA | CLI oficial de Anthropic |
| **OpenClaw** | Plataforma de asistente de IA autoalojada | Compatible con flujos de trabajo de comandos `/vxon` basados en Skills |
| **Cursor** | Editor de código nativo de IA | Basado en VS Code |
| **Windsurf** | Editor de código con IA | Por Codeium |
| **Cline** | Extensión de IA para VS Code | Agente de codificación con IA de código abierto |
| **Codex CLI** | Asistente de programación de terminal con IA | CLI oficial de OpenAI |

> Cualquier herramienta que admita el protocolo Skills puede usar los Skills de Vxon.
