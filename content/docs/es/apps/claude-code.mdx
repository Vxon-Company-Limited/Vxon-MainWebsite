## Método de configuración del modelo de IA

### Guía gráfica para Windows

#### 1. Instalar el entorno Node.js

Claude Code requiere un entorno Node.js para ejecutarse.

<Callout type="info" title="Pasos de instalación del entorno Node.js">
  - Abra su navegador y visite https://nodejs.org/
  - Haga clic en la versión "LTS" para descargar (se recomienda la versión de soporte a largo plazo)
  - Después de descargar, haga doble clic en el archivo .msi
  - Siga el asistente de instalación para completar la instalación, manteniendo la configuración predeterminada
</Callout>
<Callout type="warn" title="Notas para Windows">
  - Se recomienda usar PowerShell en lugar de CMD
  - Si encuentra problemas de permisos, intente ejecutar como administrador
  - Algunos antivirus pueden reportar falsos positivos; puede que necesite agregar una excepción
</Callout>

<Callout type="info" title="Verificar instalación exitosa">
  Después de la instalación, abra PowerShell o CMD e ingrese los siguientes comandos:

  ```bash
  node --version
  npm --version
  ```

  Si se muestran los números de versión, la instalación fue exitosa.
</Callout>

#### 2. Instalar Git Bash

<Callout type="warn" title="Notas para Windows">
  En un entorno Windows, se requiere Git Bash para instalar Claude Code. Después de la instalación, la configuración de variables de entorno y el uso de Claude Code se realizarán en PowerShell o CMD normal.
</Callout>

<Callout type="info" title="Descargar e instalar Git para Windows">
  - Visite https://git-scm.com/downloads/win
  - Haga clic en "Download for Windows" para descargar el instalador
  - Ejecute el archivo de instalación .exe descargado
  - Mantenga la configuración predeterminada durante la instalación y haga clic en "Next" para completar la instalación
</Callout>

![windows-img-06.webp](/assets/claude_code/windows-img-06.webp)

![windows-img-07.webp](/assets/claude_code/windows-img-07.webp)

![windows-img-08.webp](/assets/claude_code/windows-img-08.webp)

<Callout type="info" title="Verificar instalación de Git Bash">
  Después de la instalación, abra Git Bash e ingrese el siguiente comando para verificar:

  ```bash
  git --version
  ```

  Si se muestra un número de versión, la instalación fue exitosa.
</Callout>

#### 3. Instalar Claude Code

<Callout type="info" title="Instalar Claude Code">
  Abra PowerShell y ejecute el siguiente comando:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```

  Este comando descargará e instalará la última versión de Claude Code desde el repositorio oficial de npm.
</Callout>

![windows-img-09.webp](/assets/claude_code/windows-img-09.webp)

<Callout type="info" title="Agregar ~/.local/bin al PATH (solo si se solicita)">
  ```powershell
  [Environment]::SetEnvironmentVariable('Path', ([Environment]::GetEnvironmentVariable('Path','User') + ";$HOME\.local\bin"), 'User')
  ```
</Callout>

<Callout type="info" title="Verificar instalación de Claude Code">
  Después de la instalación, ingrese el siguiente comando para verificar si se instaló correctamente:

  ```bash
  claude --version
  ```

  Si se muestra un número de versión, ¡felicidades! Claude Code se ha instalado correctamente.
</Callout>
#### 4. Configurar variables de entorno

<Callout type="info" title="Comando de configuración con un clic (Sistema Windows)">
  Para permitir que Claude Code se conecte a su servicio de retransmisión, necesita configurar múltiples variables de entorno:
</Callout>

```powershell
iex (irm 'https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/claude-cli-setup.ps1')
```

![windows-configure](/assets/claude_code/windows_configure.png)

#### 5. Comenzar a usar Claude Code

¡Ahora puede comenzar a usar Claude Code!

<Callout type="info" title="Iniciar Claude Code">
  Abra PowerShell e inicie Claude Code directamente:

  ```bash
  claude
  ```

  Para usar en un proyecto específico:

  ```bash
  # Navegue al directorio de su proyecto
  cd C:\path\to\your\project

  # Inicie Claude Code
  claude
  ```
</Callout>

#### 4. Problemas comunes en macOS

<Callout type="info" title="La configuración de seguridad de macOS impide la ejecución">
  Si el sistema impide que Claude Code se ejecute:

  - Abra "Preferencias del Sistema" → "Seguridad y Privacidad"
  - Haga clic en "Abrir de todos modos" o "Permitir"
  - O ejecute en Terminal: `sudo spctl --master-disable`
</Callout>

#### 4. Problemas comunes en Linux

<Callout type="info" title="Bibliotecas de dependencias faltantes">
  Algunas distribuciones de Linux requieren la instalación de dependencias adicionales:

  ```bash
  # Ubuntu/Debian
  sudo apt install build-essential

  # CentOS/RHEL
  sudo dnf groupinstall "Development Tools"
  ```
</Callout>

<Callout type="info" title="Las variables de entorno no surten efecto">
  Verifique los siguientes puntos:

  - Confirme que modificó el archivo de configuración correcto (`.bashrc` o `.zshrc`)
  - Reinicie la terminal o ejecute `source ~/.bashrc`
  - Verifique la configuración: `echo $ANTHROPIC_BASE_URL`
</Callout>
