## Características principales

### 🔌 Gestión de proveedores
- **Cambio con un clic** — Cambie entre configuraciones de API de Claude Code, Codex y Gemini al instante, sin editar manualmente variables de entorno ni archivos de configuración
- **Soporte multi-endpoint** — Configure múltiples endpoints por proveedor con gestión de claves de API y pruebas de velocidad de latencia
- **Configuración de modelos en 4 niveles** — Selección granular de modelos en los niveles Haiku / Sonnet / Opus / Personalizado

### 🛠️ Gestión de servidores MCP
- **Gestión unificada entre aplicaciones** — Gestione servidores MCP para Claude / Codex / Gemini desde un solo panel
- **Tres tipos de transporte** — Compatible con stdio, HTTP y SSE (Server-Sent Events)
- **Sincronización automática** — Importación/exportación unificada con sincronización bidireccional

### 💬 Gestión de prompts
- **Prompts del sistema con múltiples presets** — Presets ilimitados con cambio rápido
- **Soporte entre aplicaciones** — Claude (`CLAUDE.md`), Codex (`AGENTS.md`), Gemini (`GEMINI.md`)
- **Editor Markdown** — CodeMirror 6 con vista previa en vivo

### 🌐 Soporte multiplataforma
- **Aplicación de escritorio** — Instaladores nativos para Windows, macOS y Linux
- **Versión web** — Interfaz accesible por navegador para servidores headless / entornos SSH
- **Versión CLI** — Modos interactivo con menú y de línea de comandos

## Integración con Vxon

CC Switch admite el protocolo Deep Link `ccswitch://`, permitiendo la importación de configuración de proveedor con un clic desde la página de gestión de tokens de Vxon.

### Pasos de configuración

1. **En la página de gestión de tokens de Vxon, haga clic en el menú desplegable del token correspondiente**
   Seleccione la opción **CC Switch** del menú. El sistema lanzará automáticamente CC Switch y abrirá el diálogo de configuración.

2. **Complete la configuración en el diálogo**
   ![Diálogo de configuración de CC Switch](/assets/cc_switch/fill_dialog.png)

   Descripción de los campos:
   - **Aplicación**: Cambie el tipo de aplicación en la parte superior — **Claude** / **Codex** / **Gemini**, seleccione la aplicación de destino según sea necesario
   - **Nombre**: Ingrese un nombre para esta configuración (ej. `Mi Claude`) para identificar y cambiar fácilmente en CC Switch después
   - **Modelo principal** (obligatorio) — El modelo principal a usar por defecto
   - **Modelo Haiku** — Modelo ligero y rápido
   - **Modelo Sonnet** — Modelo equilibrado
   - **Modelo Opus** — Modelo más capaz

   Todos los modelos son selecciones desplegables; los campos no seleccionados muestran "Seleccione un modelo".

3. **Finalizar**
   Haga clic en **"Abrir CC Switch"** para importar la configuración en CC Switch y comenzar a usarlo; haga clic en **"Cancelar"** para descartar.

## Instalación

### macOS (Homebrew recomendado)

```shell
brew tap farion1231/ccswitch
brew install --cask cc-switch
```

### Windows

Descargue el instalador `.msi` o el `.zip` portátil desde [Releases](https://github.com/farion1231/cc-switch/releases).

### Linux

Descargue el paquete `.deb` o `.AppImage` desde [Releases](https://github.com/farion1231/cc-switch/releases).

Usuarios de ArchLinux:

```shell
paru -S cc-switch-bin
```

### Versión web (servidores headless / SSH)

```shell
wget https://github.com/farion1231/cc-switch/releases/latest/download/cc-switch-web-linux-x64.tar.gz
tar -xzf cc-switch-web-linux-x64.tar.gz
cd cc-switch-web/
./cc-switch-web
```

Puerto predeterminado `17666`, acceda a través del navegador en `http://localhost:17666`.
