<Callout type="info" title="Introducción del proyecto">
  Droid CLI es una herramienta de línea de comandos desarrollada por Factory AI, diseñada para ejecutarse como un agente de ingeniería de software con IA. Permite a los usuarios interactuar con diversos modelos de lenguaje de gran escala a través de la terminal, construir, depurar y refactorizar código, e incluso crear aplicaciones completas.

  - Página oficial: [https://factory.ai/product/cli](https://factory.ai/product/cli)
  - Documentación oficial: [https://docs.factory.ai/cli/getting-started/quickstart](https://docs.factory.ai/cli/getting-started/quickstart)
</Callout>

## Método de configuración del modelo de IA

### Guía gráfica para Windows

#### 1. Abrir Terminal

![windows_open_terminal](/assets/factory_droid_cli/windows_open_terminal.png)

#### 2. Instalar Factory Droid CLI

Comando de instalación oficial con un clic:

<Callout type="info" title="Comando de instalación con un clic">
  ```powershell
  irm https://app.factory.ai/cli/windows | iex
  ```
</Callout>

![windows-install](/assets/factory_droid_cli/windows_install_droid.webp)

#### 3. Modificar archivo de configuración

Droid CLI requiere modificar el archivo de configuración para usar APIs de terceros.

![windows-configure.webp](/assets/factory_droid_cli/factory_cli_setup_windows.png)

<Callout type="info" title="Modificar variables de entorno">
  ```powershell
  iex (irm 'https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/factory-cli-setup.ps1')
  ```
</Callout>

#### 4. Comenzar a usar Droid CLI

¡Ahora puede comenzar a usar Droid CLI!

<Callout type="info" title="Iniciar Droid CLI">
  Inicie Droid CLI directamente:

  ```bash
  droid
  ```

  Usar en un proyecto específico:

  ```bash
  # Navegue al directorio de su proyecto
  cd C:\path\to\your\project

  # Inicie Droid CLI
  droid
  ```

  Presione Enter para iniciar Droid CLI.
</Callout>

Droid CLI requiere que los usuarios inicien sesión en una cuenta oficial (gratuita) antes de usarlo.

#### 5. Solución de problemas comunes en Windows

<Callout type="info" title='La instalación muestra error de "permiso denegado"'>
  Esto generalmente es un problema de permisos. Pruebe las siguientes soluciones:

  - Ejecute PowerShell como administrador
  - O configure `npm` para usar el directorio del usuario: `npm config set prefix %APPDATA%\npm`
</Callout>

<Callout type="info" title="Error de política de ejecución de PowerShell">
  Si encuentra una restricción de política de ejecución, ejecute:

  ```powershell
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  ```
</Callout>

### Guía gráfica para macOS/Linux

#### 1. Instalar Droid CLI

<Callout type="info" title="Instalar Droid CLI">
  Abra su terminal y ejecute el siguiente comando:

  ```bash
  curl -fsSL https://app.factory.ai/cli | sh
  ```
</Callout>

![macos-open-terminal](/assets/factory_droid_cli/macos_install_droid.webp)

![macos-img-02.webp](/assets/factory_droid_cli/macos_install_droid_2.webp)

Siga las instrucciones de instalación para modificar las variables de entorno (copie directamente el código de las instrucciones de instalación):

Para Linux, elija `~/.bashrc` o `~/.zshrc` según corresponda.

<Callout type="info" title="Variables de entorno de Droid CLI (Solo ejemplo)">
  ```bash
  echo 'export PATH=/Users/modify_here/.local/bin:$PATH' >> ~/.zshrc
  source ~/.zshrc
  ```
</Callout>

#### 2. Modificar archivo de configuración

Droid CLI requiere modificar el archivo de configuración para usar APIs de terceros.

<Callout type="info" title="Modificación del archivo de configuración con un clic">
  ```bash
  curl -fsSL https://raw.githubusercontent.com/Vxon/vxon-docs/refs/heads/main/helper/factory-cli-setup.sh | bash
  ```
</Callout>

![macos-img-03.webp](/assets/factory_droid_cli/macos_configure.png)

#### 3. Comenzar a usar Droid CLI

¡Ahora puede comenzar a usar Droid CLI!

  # Inicie Droid CLI
