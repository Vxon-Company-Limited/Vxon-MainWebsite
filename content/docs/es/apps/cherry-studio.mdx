<Callout type="info" title="Opciones de configuración de chat">
  En la Configuración del sistema -> Configuración de chat de la consola de Vxon, se pueden agregar las siguientes
  opciones de acceso rápido para completar fácilmente Cherry Studio con un solo
  clic en la página de gestión de tokens:
</Callout>

    ```json
    { "Cherry Studio": "cherrystudio://providers/api-keys?v=1&data={cherryConfig}" }
    ```

<Callout type="info">
  🍒 Cherry Studio es un potente cliente de IA de escritorio diseñado para usuarios
  profesionales, que integra más de 30 asistentes inteligentes específicos por industria para satisfacer
  las necesidades de diversos escenarios de trabajo y mejorar significativamente la eficiencia laboral.
</Callout>
