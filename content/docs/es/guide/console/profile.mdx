---
title: Configuración Personal
---

Aquí puede ver la información de la cuenta, gestionar las vinculaciones de cuenta, realizar configuraciones de seguridad y más.

## Ver Modelos Disponibles

Aquí puede ver los modelos disponibles para su cuenta actual. Haga clic en el nombre de un modelo para copiarlo.

![可用模型](/assets/guide/available-models.png)

## Vinculación de Cuenta

Aquí puede realizar operaciones de vinculación de cuenta.

![账户绑定](/assets/guide/account-bind.png)

## Configuración de Seguridad

Aquí puede cambiar su contraseña, restablecer su clave de API y realizar otras operaciones relacionadas.

![安全设置](/assets/guide/account-security.png)

## Otras Configuraciones

### Configuración de Notificaciones

Aquí puede configurar cómo recibir notificaciones. Actualmente se admiten correo electrónico y Webhook.

![邮件通知](/assets/guide/account-notification-mail.png)

![Webhook](/assets/guide/account-notification-webhook.png)

### Configuración de Precios

Aquí puede establecer si acepta modelos sin un precio configurado.

![价格设置](/assets/guide/account-price.png)

### Registro de IP

Aquí puede elegir habilitar el registro de IP. Si está habilitado, las direcciones IP se mostrarán en los registros.

![IP设置](/assets/guide/account-ip-log.png)
