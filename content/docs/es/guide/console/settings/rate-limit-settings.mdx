---
title: Configuración de Límite de Velocidad
---

Aquí puede configurar los ajustes relacionados con el límite de velocidad de solicitudes de modelos.

Ejemplo de límite de velocidad por grupo:

```json
{
  "default": [200, 100],
  "vip": [0, 1000]
}
```
