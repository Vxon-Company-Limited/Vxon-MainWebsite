---
title: Guía de configuración de variables de entorno
---

Este documento proporciona todas las variables de entorno compatibles con Vxon y sus instrucciones de configuración. Puede personalizar el comportamiento del sistema configurando estas variables de entorno.

<Callout type="info" title="Consejo">
  Vxon admite la lectura de variables de entorno desde archivos `.env`. Consulte el archivo `.env.example`
  y renómbrelo a `.env` cuando lo use.
</Callout>

## Configuración básica

| Variable de entorno | Descripción           | Valor predeterminado | Ejemplo               |
| -------------------- | --------------------- | ------------- | --------------------- |
| `PORT`               | Puerto de escucha del servicio | `3000`        | `PORT=8080`           |
| `TZ`                 | Configuración de zona horaria | -             | `TZ=America/New_York` |
| `VERSION`            | Sobrescribir número de versión en ejecución | -     | `VERSION=1.2.3`       |

## Configuración de base de datos

| Variable de entorno          | Descripción                                    | Valor predeterminado      | Ejemplo                                                                                                                             |
| ----------------------------- | ---------------------------------------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `SQL_DSN`                     | Cadena de conexión a la base de datos          | SQLite (`one-api.db`)     | MySQL: `SQL_DSN=root:123456@tcp(localhost:3306)/vxon` \| PostgreSQL: `SQL_DSN=postgresql://root:123456@postgres:5432/vxon` |
| `SQL_MAX_IDLE_CONNS`          | Conexiones inactivas máximas en el pool        | `100`                     | `SQL_MAX_IDLE_CONNS=50`                                                                                                          |
| `SQL_MAX_OPEN_CONNS`          | Conexiones abiertas máximas en el pool         | `1000`                    | `SQL_MAX_OPEN_CONNS=500`                                                                                                         |
| `SQL_MAX_LIFETIME`            | Tiempo de vida máximo de conexión (segundos)   | `60`                      | `SQL_MAX_LIFETIME=120`                                                                                                          |
| `LOG_SQL_DSN`                 | Cadena de conexión separada para tabla de logs  | -                         | `LOG_SQL_DSN=root:123456@tcp(localhost:3306)/oneapi_logs`                                                                        |
| `SQLITE_PATH`                 | Ruta de la base de datos SQLite                | `one-api.db`              | `SQLITE_PATH=/var/lib/vxon/vxon.db`                                                                                        |

## Configuración multinodo y de seguridad

| Variable de entorno              | Descripción                                                  | Valor predeterminado | Ejemplo                                        |
| --------------------------------- | ------------------------------------------------------------ | ------------- | ------------------------------------------- |
| `SESSION_SECRET`                  | Secreto de sesión (requerido para despliegue multimáquina)   | -             | `SESSION_SECRET=your_session_secret`        |
| `CRYPTO_SECRET`                   | Secreto de cifrado (cifra contenido de la base de datos, predeterminado a SESSION_SECRET) | -             | `CRYPTO_SECRET=your_crypto_secret`          |
| `FRONTEND_BASE_URL`               | URL base del frontend (usada por nodos esclavos, redirige rutas no coincidentes a esta dirección) | -             | `FRONTEND_BASE_URL=https://<your-vxon-domain>` |
| `NODE_TYPE`                       | Tipo de nodo                                                 | `master`      | `NODE_TYPE=slave`                           |
| `TLS_INSECURE_SKIP_VERIFY`        | Omitir globalmente la verificación de certificados TLS       | `false`       | `TLS_INSECURE_SKIP_VERIFY=true`             |
| `TRUSTED_REDIRECT_DOMAINS`        | Lista de dominios de redirección confiables (separados por comas) | -             | `TRUSTED_REDIRECT_DOMAINS=example.com,api.example.com` |

<Callout type="warn" title="Notas sobre SESSION_SECRET">
  `SESSION_SECRET` no puede establecerse como `random_string`, de lo contrario el programa se negará a iniciar. Todos los nodos deben usar el mismo secreto para despliegue multimáquina.
</Callout>

## Configuración de retransmisión y proxy

| Variable de entorno                  | Descripción                                                  | Valor predeterminado | Ejemplo                             |
| ------------------------------------- | ------------------------------------------------------------ | ------------- | -------------------------------- |
| `RELAY_TIMEOUT`                       | Tiempo de espera de solicitud de retransmisión (segundos), 0 para ilimitado | `0`           | `RELAY_TIMEOUT=60`               |
| `STREAMING_TIMEOUT`                   | Tiempo de espera de respuesta única en streaming (segundos)  | `300`         | `STREAMING_TIMEOUT=120`          |
| `RELAY_MAX_IDLE_CONNS`                | Conexiones inactivas máximas en el pool del cliente HTTP de retransmisión | `500`         | `RELAY_MAX_IDLE_CONNS=1000`      |
| `RELAY_MAX_IDLE_CONNS_PER_HOST`       | Conexiones inactivas máximas por host en el pool del cliente HTTP de retransmisión | `100`         | `RELAY_MAX_IDLE_CONNS_PER_HOST=200` |
| `MAX_FILE_DOWNLOAD_MB`                | Tamaño máximo de descarga de archivos (MB)                   | `64`          | `MAX_FILE_DOWNLOAD_MB=128`       |
| `MAX_REQUEST_BODY_MB`                 | Tamaño máximo del cuerpo de solicitud (MB, contado después de descompresión; previene zip bomb/OOM) | `128`         | `MAX_REQUEST_BODY_MB=256`        |
| `STREAM_SCANNER_MAX_BUFFER_MB`        | Tamaño máximo del buffer del escáner de flujo SSE (MB)       | `64`          | `STREAM_SCANNER_MAX_BUFFER_MB=128` |

<Callout type="warn" title="Advertencia sobre la configuración de RELAY_TIMEOUT">
  Tenga precaución al configurar la variable de entorno `RELAY_TIMEOUT`. Establecerla demasiado corta puede causar los siguientes problemas:
</Callout>

    - La API upstream ha completado la solicitud y cobrado, pero la facturación local falló debido al tiempo de espera

    - Llevando a desincronización de facturación, lo que puede resultar en pérdidas del sistema

    - Se recomienda no configurarla a menos que sepa lo que está haciendo

## Ejemplo de despliegue multimáquina

En escenarios de despliegue multimáquina, se deben configurar las siguientes variables de entorno:

### Configuración del nodo maestro

```bash
# Database Configuration - Use a remote database
SQL_DSN=root:password@tcp(db-server:3306)/oneapi

# Security Configuration
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis Cache Configuration
REDIS_CONN_STRING=redis://default:password@redis-server:6379
```

### Configuración del nodo esclavo

```bash
# Database Configuration - Use the same remote database
SQL_DSN=root:password@tcp(db-server:3306)/oneapi

# Security Configuration - Use the same secret as the master node
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis Cache Configuration - Use the same Redis as the master node
REDIS_CONN_STRING=redis://default:password@redis-server:6379

# Node Type Setting
NODE_TYPE=slave

# Optional: Frontend Base URL
# FRONTEND_BASE_URL=https://<your-vxon-domain>

# Optional: Synchronization Frequency
SYNC_FREQUENCY=60
```

<Callout type="info" title="Configuración completa del clúster">
  Este es solo un ejemplo básico de configuración multinodo. Para la configuración completa del despliegue en clúster, descripción de la arquitectura y mejores prácticas, consulte la [Guía de despliegue en clúster](/es/docs/installation/deployment-methods/cluster-deployment).
</Callout>

## Ejemplo de variables de entorno en Docker Compose

A continuación se muestra un breve ejemplo de configuración de variables de entorno en un archivo de configuración de Docker Compose:

```yaml
services:
  vxon:
    image: vxon/vxon:latest
    environment:
      - TZ=Asia/Shanghai
      - SQL_DSN=root:123456@tcp(mysql:3306)/oneapi
      - REDIS_CONN_STRING=redis://default:redispw@redis:6379
      - SESSION_SECRET=your_unique_session_secret
      - CRYPTO_SECRET=your_unique_crypto_secret
      - MEMORY_CACHE_ENABLED=true
      - GENERATE_DEFAULT_TOKEN=true
      - STREAMING_TIMEOUT=120
      - CHANNEL_UPDATE_FREQUENCY=1440
```

Para una configuración completa de Docker Compose, incluyendo más opciones de configuración de variables de entorno, consulte el documento [Instrucciones de configuración de Docker Compose](/es/docs/installation/config-maintenance/docker-compose-yml).
